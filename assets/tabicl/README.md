# Optional TabICL checkpoint

To use the checkpoint-backed TabICL options or build the complete macOS application, obtain the upstream checkpoint independently and place it here as `tabicl-classifier-v2-20260212.ckpt`. The application checks the file against the checksum in `src/sensor_app/model_assets.py`. See the [TabICL model repository](https://huggingface.co/jingang/TabICL).
